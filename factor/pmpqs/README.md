首项系数取素数平方的二次筛（pmpqs）
================================

`factor/pmpqs/` 是一个多项式二次筛的变体，与 `factor/mpqs/`（见那一份
README）**只差首项系数 $A$ 的取法**：

- MPQS：$A$ 由因子基内许多小素数之积构成，且 $A$ 是平方；
- pmpqs：$A = d^2$，$d$ 是**一个素数**。

这个变体在文献里没有名字，所以按其定义特征取名 pmpqs。原名 `smallmpqs`
只比 `mpqs` 多一个前缀，读起来像"小号 MPQS"，没有传达任何信息，已弃用。
计算器命令 `pmpqs(n)`，旧命令名不留别名。


一、多项式怎么来
----------------

取素数 $d$ 满足

$$(n/d) = 1 \quad\text{且}\quad d \equiv 3 \pmod 4$$

$(n/d) = 1$ 保证 $n$ 在模 $d$ 下有平方根；$d \equiv 3 \pmod 4$ 让 Hensel
提升的导数非零。令 $h_1 = \sqrt{n} \bmod d$（用 $n^{(d-1)/2} \bmod d$
由欧拉判据算出），再把 $h_1$ 提升成模 $d^2$ 的平方根 $b$：

$$h_1 = n^{(d-3)/4} \bmod d, \qquad h_2 = (2h_1)^{-1}\cdot\frac{n - h_1^2}{d} \bmod d$$
$$b = h_1 + h_2 d \pmod{d^2}$$

于是

$$a = d^2, \qquad c = \frac{b^2 - n}{d^2}, \qquad f(x) = a x^2 + b x + c$$

也就是 $n = b^2 - c d^2$。`smpqs_nextD` 逐个取素数（`mpz_nextprime`），
`smpqs_computeB` 做上面这套提升，并保证 $b < a/2$ 以减少筛法区间的偏移。

$a$ 是素数的平方，所以按 MPQS 的展开，$a x^2 + bx + c$ 里那一项 $a$ 自动光滑；
与 MPQS 相同的结论：只需对 $a x^2 + b x + c$ 判光滑。


二、和 MPQS 的取舍
------------------

**好处。** 构造多项式只需一次模幂加一次模逆，完全不需要在因子基里挑素数、
配比特数、逼近 $\sqrt{2n}/M$——`poly.c` 里那套 `poly_init` 的分箱逻辑在这里
一行都用不上。每个多项式独立，天然适合并行，也不存在"上一条多项式的
因子把这一条卡住"的情况。

**代价。** 损失了 MPQS 最重要的那个优化：$A$ 贴近 $\sqrt{2N}/S$ 能压低
$Q(x)$ 的平均值，而 $d$ 只能取素数，粒度粗得多——$d$ 从 1 跳到下一个素数
时 $d^2$ 的相对变化在 $d \approx n^{1/4}$ 量级已经是 $\Theta(1/\log d)$，
远粗于 $A$ 的连续可调。筛法值的平均值因此明显偏大，判光滑率下降。
实现里 `pmpqs_choose_multiplier` 会先挑乘子来缓解，但这不能替代对 $A$ 的
连续调节。

这也是它在实践中不如 SIQS/MPQS 的原因：省掉的那部分复杂度换不来等价的
常数因子收益。


三、适用范围
------------

代码里有硬下界：$n \le 2^{20}$ 直接返回失败（`mpz_cmp_ui(n, 1 << 20) <= 0`）。
不写保存文件、不支持断点续算，失败时返回空指针，计算器命令不打印任何东西。
适合当作一个结构清晰的教学实现或交叉验证基准，不适合当主力分解方法。
